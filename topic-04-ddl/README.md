# Library Management System — SQL DDL

## 📌 Мета

Реалізувати повну структуру бази даних для керування бібліотекою: книгами, авторами, жанрами, категоріями, фізичними примірниками, читачами, видачами, резервуваннями та відгуками.

DDL-скрипт створює таблиці, первинні ключі, зовнішні ключі, обмеження цілісності, унікальні індекси, звичайні індекси та початкові довідникові дані.

---

## 🐘 PostgreSQL compatibility

Скрипт орієнтований на PostgreSQL і використовує:

- `GENERATED BY DEFAULT AS IDENTITY` для автоінкрементних первинних ключів;
- `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `CHECK` constraints;
- `ON DELETE RESTRICT`, `ON DELETE CASCADE`, `ON DELETE SET NULL` для правил видалення;
- partial unique index для контролю активної видачі примірника;
- `CURRENT_TIMESTAMP` для дат створення операцій.

## 📄 Table descriptions

### `books`

Зберігає книгу як бібліографічну сутність незалежно від кількості фізичних копій.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Унікальний ідентифікатор книги |
| `title` | `varchar(255)` | NOT NULL | Назва книги |
| `isbn` | `varchar(17)` | UNIQUE, NOT NULL | Унікальний ISBN |
| `publication_year` | `smallint` | CHECK `1000..2100` | Рік видання |

---

### `genre`

Довідник жанрів для класифікації книг за змістом або літературним типом.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор жанру |
| `name` | `varchar(255)` | UNIQUE, NOT NULL | Назва жанру |

---

### `book_genre`

Проміжна таблиця для зв’язку many-to-many між книгами та жанрами.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `book_id` | `int` | PK, FK → `books.id` | Посилання на книгу |
| `genre_id` | `int` | PK, FK → `genre.id` | Посилання на жанр |

Primary key: (`book_id`, `genre_id`).

---

### `authors`

Зберігає авторів літературних творів.

| Field | Type | Constraints | Description |

| `first_name` | `varchar(50)` | NOT NULL | Ім’я автора |
| `last_name` | `varchar(50)` | NOT NULL | Прізвище автора |

---

### `book_authors`

Проміжна таблиця для зв’язку many-to-many між книгами та авторами.

| Field | Type | Constraints | Description |
|---|---|---|---|

| `author_id` | `int` | PK, FK → `authors.id` | Посилання на автора |

Primary key: (`book_id`, `author_id`).

---

Довідник бізнес- або організаційних категорій книг.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор категорії |
| `name` | `varchar(40)` | UNIQUE, NOT NULL | Назва категорії |

---

### `book_categories`

Проміжна таблиця для зв’язку many-to-many між книгами та категоріями.

| Field | Type | Constraints | Description |
|---|---|---|---|

| `category_id` | `int` | PK, FK → `categories.id` | Посилання на категорію |

Primary key: (`book_id`, `category_id`).

### `members`

Зберігає читачів бібліотеки, які можуть брати книги, резервувати їх і залишати відгуки.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор читача |
| `first_name` | `varchar(50)` | NOT NULL | Ім’я читача |
| `last_name` | `varchar(50)` | NOT NULL | Прізвище читача |
| `email` | `varchar(100)` | UNIQUE, NOT NULL | Email |
| `login` | `varchar(100)` | UNIQUE, NOT NULL | Логін |
| `password_hash` | `varchar(128)` | NOT NULL | Хеш пароля |
| `phone` | `varchar(20)` | NOT NULL | Телефон |

### `copy_statuses`

Довідник статусів фізичних примірників книг.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор статусу |
| `name` | `varchar(15)` | UNIQUE, NOT NULL | Назва статусу |

Default values: `available`, `borrowed`, `reserved`, `lost`.

---

### `book_copies`

Зберігає фізичні примірники книг. Саме примірник видається, резервується або списується.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор примірника |
| `book_id` | `int` | FK → `books.id`, NOT NULL | Книга, до якої належить примірник |
| `barcode` | `varchar(30)` | UNIQUE, NOT NULL | Унікальний штрихкод |
| `copy_status_id` | `int` | FK → `copy_statuses.id`, NOT NULL | Поточний статус примірника |

---

### `borrowing_statuses`

Довідник статусів операцій видачі.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор статусу |
| `name` | `varchar(15)` | UNIQUE, NOT NULL | Назва статусу |

Default values: `active`, `returned`, `overdue`.

---

### `borrowings`

Зберігає загальну інформацію про операцію видачі книг читачу.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор видачі |
| `member_id` | `int` | FK → `members.id`, NOT NULL | Читач, який взяв книги |
| `borrowing_date` | `timestamp` | NOT NULL, DEFAULT `CURRENT_TIMESTAMP` | Дата видачі |
| `status_id` | `int` | FK → `borrowing_statuses.id`, NOT NULL | Статус видачі |

---

### `borrowing_items`

Зберігає конкретні фізичні примірники в межах однієї операції видачі.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор позиції видачі |
| `borrowing_id` | `int` | FK → `borrowings.id`, NOT NULL | Посилання на видачу |
| `book_copy_id` | `int` | FK → `book_copies.id`, NOT NULL | Виданий примірник |
| `return_date` | `timestamp` | nullable | Фактична дата повернення |
| `due_date` | `timestamp` | NOT NULL | Кінцева дата повернення |

Additional rules:

- `uq_borrowing_copy` забороняє дублювання одного примірника в межах однієї видачі;
- `uq_borrowing_copy_active` забороняє одночасну активну видачу одного фізичного примірника, якщо `return_date IS NULL`.

Довідник статусів резервування.

|---|---|---|---|

Default values: `pending`, `fulfilled`, `cancelled`.

### `reservations`

Зберігає загальну інформацію про резервування книг читачем.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор резервування |
| `member_id` | `int` | FK → `members.id`, NOT NULL | Читач, який створив резервування |
| `reservation_date` | `timestamp` | NOT NULL, DEFAULT `CURRENT_TIMESTAMP` | Дата резервування |
| `status_id` | `int` | FK → `reservation_statuses.id`, NOT NULL | Статус резервування |

### `reservation_items`

Зберігає книги або конкретні примірники в межах резервування.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор позиції резервування |
| `reservation_id` | `int` | FK → `reservations.id`, NOT NULL | Посилання на резервування |
| `book_id` | `int` | FK → `books.id`, NOT NULL | Зарезервована книга |
| `book_copy_id` | `int` | FK → `book_copies.id`, nullable | Конкретний примірник, якщо вже призначений |

Business rule: резервування створюється на рівні книги, тому `book_copy_id` може бути `NULL`, доки конкретний примірник ще не призначено.

### `book_reviews`

Зберігає відгуки та оцінки книг від читачів.

| Field | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INT` | PK, identity | Ідентифікатор відгуку |
| `member_id` | `int` | FK → `members.id`, NOT NULL | Автор відгуку |
| `book_id` | `int` | FK → `books.id`, NOT NULL | Книга |
| `review_text` | `text` | nullable | Текст відгуку |

## 🔗 Relationships and ON DELETE logic

| Child table | Field | Parent table | ON DELETE | Meaning |
|---|---|---|---|---|
| `book_copies` | `book_id` | `books.id` | RESTRICT | Книгу не можна видалити, якщо існують її примірники |
| `book_copies` | `copy_status_id` | `copy_statuses.id` | RESTRICT | Статус не можна видалити, якщо він використовується |
| `borrowings` | `member_id` | `members.id` | RESTRICT | Читача не можна видалити, якщо є історія видач |
| `borrowings` | `status_id` | `borrowing_statuses.id` | RESTRICT | Статус видачі не можна видалити, якщо він використовується |
| `borrowing_items` | `borrowing_id` | `borrowings.id` | CASCADE | При видаленні видачі видаляються її позиції |
| `borrowing_items` | `book_copy_id` | `book_copies.id` | RESTRICT | Примірник не можна видалити, якщо він є в історії видач |
| `reservations` | `member_id` | `members.id` | RESTRICT | Читача не можна видалити, якщо є історія резервувань |
| `reservations` | `status_id` | `reservation_statuses.id` | RESTRICT | Статус резервування не можна видалити, якщо він використовується |
| `reservation_items` | `reservation_id` | `reservations.id` | CASCADE | При видаленні резервування видаляються його позиції |
| `reservation_items` | `book_id` | `books.id` | RESTRICT | Книгу не можна видалити, якщо на неї є резервування |
| `reservation_items` | `book_copy_id` | `book_copies.id` | SET NULL | Якщо примірник видалено, резервування лишається на рівні книги |
| `book_reviews` | `member_id` | `members.id` | CASCADE | При видаленні читача видаляються його відгуки |
| `book_reviews` | `book_id` | `books.id` | CASCADE | При видаленні книги видаляються її відгуки |

> Note: у таблицях `book_genre`, `book_authors`, `book_categories` зв’язки many-to-many оголошені всередині `CREATE TABLE` як `DEFERRABLE INITIALLY IMMEDIATE`.

## 🧩 Main business rules

1. Одна книга може мати багато фізичних примірників.
2. Один фізичний примірник може бути активним лише в одній незавершеній видачі.
3. Одна операція видачі може містити кілька примірників.
4. Резервування створюється на рівні книги, а конкретний примірник може бути призначений пізніше.
5. Один читач може залишити лише один відгук на одну книгу.
6. Оцінка книги обмежена діапазоном від `1` до `5`.
7. Рік публікації книги обмежений діапазоном від `1000` до `2100`.

## 🚀 Indexing strategy

| Index | Table | Columns | Purpose |
|---|---|---|---|
| `uq_borrowing_copy` | `borrowing_items` | `borrowing_id`, `book_copy_id` | Заборона дублювання примірника в одній видачі |
